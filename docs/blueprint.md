# **App Name**: DigiCondo

## Core Features:

- Autenticação de Usuários: Implementação de autenticação segura para os diferentes papéis: residente, supervisor, administrador e síndico. Cada papel terá permissões específicas.
- Reserva de Área de Lazer: Sistema para reserva da área de lazer (Salão de Festas) com geração automática de código Pix/Boleto e confirmação automática após o pagamento. Inclui taxas de reagendamento.
- Gestão de Anúncios e Notificações: Sistema para registrar e exibir anúncios, avisos de reunião e outras informações relevantes para os moradores.  Implementar sistema de notificações por email para avisos e comunicados importantes.

## Style Guidelines:

- Cor primária: Amarelo claro (#FFDA63) para o fundo, transmitindo energia e positividade.
- Cor secundária: Preto (#000000) para o texto, garantindo legibilidade e contraste.
- Cor de destaque: Azul (#2196F3) para botões de ação e links, chamando a atenção do usuário.
- Design responsivo para se adaptar a diferentes tamanhos de tela (mobile, tablet, desktop).
- Ícones claros e intuitivos para representar as diferentes funcionalidades do aplicativo.
